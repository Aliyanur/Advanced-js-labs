Factory creates objects without specifying the exact class. The object type is determined at runtime.
The difference from constructor: In Constructor caller knows exact class. And Uses new keyword directly.
In Factory, caller doesn't know exact class. Also Factory decides which object to create.

When to use? When object type depends on input and when many related classes exist.

So In this LAb 7.2 I created 3 notification classes. Implemented NotificationFactory, then used factory in app. Also I demonstrated polymophism.
