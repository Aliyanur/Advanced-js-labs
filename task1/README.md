## Overview
This project demonstrates the Higher-Order Component (HOC) pattern in React using a theme injection system.

## Implemented Features
ThemeContext with light and dark themes. ThemeProvider for global theme state
withTheme HOC for injecting theme props
withStyles HOC for styled components

## HOC Pattern
Higher-Order Component (HOC) is a function that takes a component and returns a new enhanced component.
