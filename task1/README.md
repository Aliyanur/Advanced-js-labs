The Singleton pattern ensures that a class has only one instance in the whole application. It provides a global access point to this instance. It is useful for configuration managers, database connections, or loggers where only one shared object is needed.

In this lab, I implemented a class-based Singleton and a module-based Singleton. I also tested that all instances are the same and that the data is shared between them.
