## LAB 6.1 Methodology and Approach
In this lab I worked with design patterns from Chapter 6 of Learning JavaScript Design Patterns. First, I read the definitions of three main pattern families: Creational, Structural, and Behavioral. This helped me understand what type of problem each family solve.

For Task 1, I analyzed each JavaScript snippet one by one. I looked at how objects are created, how they are connected, or how they communicate. Based on this, I selected the pattern family and then the specific pattern. I also found small code parts that clearly show the pattern and used them as evidence. All decisions are connected to Chapter 6 explanations.

For Task 2, I used the GoF table from Chapter 6 to decide if each pattern works on Class or Object level. Most patterns are object-based because they use composition and instances, not inheritance.

For Task 3, I wrote a short reflection about why pattern categorization is important. I used examples and the quote from Gamma et al. (1995) mentioned in Chapter 6.
